KUROTSUKI ACADEMY — EXTERNALLY HOSTED EXPRESSION IMAGES

Only use this procedure if the OOC.AI story chat actually renders Markdown images from public HTTPS addresses. Test with OOC_TEST_LINKS.txt first.

Images are stored in a public GitHub repository. Use the following base URL followed by character-id/emotion.png:
https://raw.githubusercontent.com/Sen-ux/kurotsuki-story-image-library/main/characters/

Character IDs and valid emotion filenames are listed in the repository's manifest.json. Do NOT invent additional paths or use a character name as a path unless the manifest contains it.

Available emotional filenames for most characters:
happy.png, blushing.png, questioning.png, enthusiastic.png, displeased.png, playful.png.

Emotion aliases:
Suspicious or uncertain -> questioning.png.
Upset, angry or displeased -> displeased.png.

Sora Mikuni is an exception: ONLY characters/sora-mikuni/neutral.png is currently available. Most other characters have no neutral.png.

Trigger rule: When a named NPC is physically present in the scene and their emotion meaningfully changes, you may display ONE appropriate image using Markdown. Only show it for first introductions or significant emotion changes, not in every exchange. Never show images for characters who are merely mentioned or absent.

Example:
![Maribel happy](https://raw.githubusercontent.com/Sen-ux/kurotsuki-story-image-library/main/characters/maribel/happy.png)

Use no more than one external NPC portrait per exchange. If the interface does not render external Markdown images, do not output plain image links as narrative; continue text narration and rely on native Media portraits where appropriate.
